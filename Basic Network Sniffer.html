Basic Network Sniffer
CodeAlpha Cyber Security Internship, Task 1, by Ayorinde Ashogbon

Ayorinde_Ashogbon_BasicNetworkSniffer

A basic network sniffer in Python using scapy. It captures live packets and prints who is talking to whom, over which protocol.

Features

  • Live captureTCP, UDP, ICMP, ARP over IPv4 and IPv6
  • Packet detailsSource and destination IPs, protocol, ports, TCP flags, length
  • ExtrasOptional payload preview and DNS query names
  • ControlBPF filters, packet count limit, save to .pcap (open in Wireshark)

Setup

pip install scapy

Windows also needs Npcap. Run with admin or root privileges.

Usage

sudo python3 sniffer.py                      # sniff everything
sudo python3 sniffer.py -i eth0 -c 50        # 50 packets on eth0
sudo python3 sniffer.py -f "tcp port 80" --payload
sudo python3 sniffer.py -o capture.pcap

How it works

scapy.sniff() reads raw frames from the interface. Each frame is layered, and the program inspects each layer with haslayer(), extracts fields, and prints a summary. Seeing the layers separately shows how data is encapsulated as it moves through the network.

Ethernet the frame read from the interface
IP source and destination addresses, protocol number
TCP / UDP / ICMP ports, TCP flags, ICMP type and code
Payload shown as a printable preview with --payload

Each box wraps the next, the same way a packet wraps its data on the wire.

Ethical use

Permission first Capture only on networks you own or have written permission to monitor.
